StampedLock

StampedLock (Java 8+) is a capability-based lock returning a stamp used to release or validate the lock.

It offers three modes: writing, reading, and an optimistic read that takes no lock at all.

Optimistic reads are extremely cheap and validated afterward, retrying if a write intervened.

Unlike ReentrantReadWriteLock, it is not reentrant and not tied to conditions.

When to use / Key points
  • Read-mostly data where optimistic reads can avoid locking entirely.
  • tryOptimisticRead() plus validate(stamp) for lock-free fast paths.
  • Supports lock conversion via tryConvertToWriteLock().
  • Not reentrant, do not re-acquire on the same thread.
Pros and Cons
Near Lock-Free Reads

Optimistic reads give near lock-free performance under low write contention.

Faster Than RRWLock

It often outperforms ReentrantReadWriteLock.

Lock Conversion

It supports upgrading locks via conversion methods.

Not Reentrant

It is not reentrant, so re-locking on the same thread deadlocks.

Easy To Misuse

The API is easy to misuse and stamps must be handled carefully.

No Condition Support

It provides no Condition support.

Code
public class Point {

    private double x, y;
    private final StampedLock sl = new StampedLock();

    public void move(double dx, double dy) {
        long stamp = sl.writeLock();
        try {
            x += dx; y += dy;
        } finally {
            sl.unlockWrite(stamp);
        }
    }

    public double distanceFromOrigin() {
        long stamp = sl.tryOptimisticRead(); // no lock
        double cx = x, cy = y;
        if (!sl.validate(stamp)) { // a write happened
            stamp = sl.readLock();
            try {
                cx = x; cy = y;
            } finally {
                sl.unlockRead(stamp);
            }
        }
        return Math.sqrt(cx * cx + cy * cy);
    }
}
How it works

tryOptimisticRead() returns a stamp without acquiring a lock.

validate(stamp) confirms no write occurred; otherwise fall back to a real read lock.

Each acquired lock is released with the matching unlock* and its stamp.
