Factory Method Pattern

Factory Method is a creational design pattern that defines an interface for creating an object but lets subclasses decide which concrete class to instantiate.

It defers instantiation to subclasses, so the client code depends only on an abstract product type rather than on concrete implementations.

This promotes loose coupling by removing the need for the client to use the new operator on specific classes.

When to use
  • When a class cannot anticipate the type of objects it must create.
  • When you want subclasses to specify the objects they create.
  • When you want to decouple client code from concrete product classes.
  • When object creation logic should be centralized in one place.
  • When you need to introduce new product types without changing client code.
Advantages
  • Removes tight coupling between the creator and concrete products.
  • Follows the single responsibility principle by isolating creation code.
  • Follows the open/closed principle: new products can be added easily.
  • Provides a single place to control how objects are created.
  • Makes the code easier to extend and maintain.
Disadvantages
  • Introduces many new subclasses, increasing code complexity.
  • Can be excessive for simple creation scenarios.
  • Requires a parallel class hierarchy for creators and products.
Code
interface Notification {
    void send(String msg);
}

class EmailNotification implements Notification {
    public void send(String msg) {
        System.out.println("Email: " + msg);
    }
}

class SmsNotification implements Notification {
    public void send(String msg) {
        System.out.println("SMS: " + msg);
    }
}

abstract class NotificationCreator {
    // The factory method
    abstract Notification create();

    public void notify(String msg) {
        Notification n = create();
        n.send(msg);
    }
}

class EmailCreator extends NotificationCreator {
    Notification create() {
        return new EmailNotification();
    }
}

void main() {
    NotificationCreator c = new EmailCreator();
    c.notify("Hello");
}
How the Factory Method works
  • Notification is the abstract product; each concrete class implements it.
  • NotificationCreator declares the abstract factory method create().
  • Subclasses like EmailCreator decide which concrete product to return.
  • The client works only with the creator and product interfaces, never with new on a concrete type.
