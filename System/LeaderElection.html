Leader Election

Leader election is the process by which distributed nodes agree on a single coordinator, or leader.

The leader takes on responsibilities that must be performed by exactly one node at a time.

If the leader fails, the remaining nodes elect a new one automatically.

Consensus algorithms like Raft and Paxos, or coordinators like ZooKeeper, implement it safely.

When to use / Key points
  • Use when a task must run on exactly one node (scheduling, sequencing, primary writes).
  • A majority quorum ensures only one leader is elected, preventing two leaders.
  • Leases/heartbeats detect leader failure and trigger re-election.
  • Fencing tokens stop a stale ex-leader from acting after it is replaced.
  • Raft, Paxos, ZooKeeper, and etcd provide battle-tested implementations.
Advantages
Single Coordinator

Guarantees exactly one coordinator, avoiding conflicting decisions across nodes.

Automatic Failover

Keeps the system running by electing a new leader when the current one dies.

Simplified Logic

Simplifies logic that would otherwise be hard to coordinate among equal peers.

Disadvantages
Potential Bottleneck

The leader can become a bottleneck and a single point of contention.

Election Storms

Election storms and split brain must be carefully prevented.

Added Complexity

Adds latency and complexity from the underlying consensus protocol.

Code
# Leader election via an atomic, expiring lock in a shared store
public class LeaderElector {

    private final StringRedisTemplate redis;
    private final String nodeId;

    public boolean tryBecomeLeader() {
        # SET key node NX EX 10 -> only one node wins
        Boolean won = redis.opsForValue()
            .setIfAbsent("cluster:leader", nodeId, Duration.ofSeconds(10));
        return Boolean.TRUE.equals(won);
    }
}
How it works

setIfAbsent is atomic, so exactly one node sets the leader key.

The 10-second TTL means a crashed leader's lock auto-expires.

Other nodes keep retrying and take over when the key frees up.

Production systems use Raft/ZooKeeper for stronger guarantees and fencing.
