Encryption (SSL, TLS)

Encryption transforms readable data into ciphertext so only holders of the key can recover it.

SSL is the deprecated predecessor of TLS; modern systems use TLS 1.2 or 1.3.

TLS secures data in transit using a handshake that combines asymmetric and symmetric cryptography.

Symmetric encryption is fast; asymmetric encryption safely exchanges the shared session key.

When to use / Key points
  • Use TLS for all network traffic, including internal service-to-service calls.
  • The handshake uses certificates (asymmetric) then switches to a symmetric session key.
  • Encrypt data at rest (AES) and data in transit (TLS) as separate concerns.
  • Prefer TLS 1.3 for fewer round trips and stronger default cipher suites.
Pros and Cons
Confidentiality and Integrity

Protects data confidentiality and integrity against eavesdropping and tampering.

Server Authentication

Certificate validation authenticates the server and optionally the client.

Faster Modern Handshake

TLS 1.3 reduces handshake latency and removes weak legacy ciphers.

Added Latency

Adds CPU and handshake latency, though modern hardware makes this small.

Certificate Management

Certificate management, rotation, and expiry add operational burden.

Misconfiguration Risk

Misconfiguration such as weak ciphers or self-signed certs undermines the protection.

Code
# application.yml: enable TLS on a Spring Boot server
# server.ssl.enabled=true, keystore holds the certificate + private key

public class TlsConfig {

    // Programmatic HTTPS connector using a keystore
    public SslContext buildContext() throws Exception {
        KeyStore ks = KeyStore.getInstance("PKCS12");
        try (InputStream in = new FileInputStream("keystore.p12")) {
            ks.load(in, "changeit".toCharArray());
        }
        KeyManagerFactory kmf = KeyManagerFactory.getInstance("SunX509");
        kmf.init(ks, "changeit".toCharArray());

        SSLContext ctx = SSLContext.getInstance("TLSv1.3");
        ctx.init(kmf.getKeyManagers(), null, new SecureRandom());
        return ctx;
    }
}
How it works

KeyStore (PKCS12) holds the server certificate chain and private key.

KeyManagerFactory exposes those keys to the TLS engine during the handshake.

SSLContext.getInstance("TLSv1.3") pins the protocol version to the modern standard.

SecureRandom supplies cryptographically strong randomness for key generation.
