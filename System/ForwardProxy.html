Forward Proxy

A forward proxy sits in front of clients and forwards their requests to the internet on their behalf.

The destination server sees the proxy's address, not the individual client's.

It is typically deployed inside an organization to control, filter, and cache outbound traffic.

In short, a forward proxy represents the client; a reverse proxy represents the server.

When to use / Key points
  • Use to enforce corporate access policies and content filtering for outbound traffic.
  • Provides client anonymity by masking the client's real IP from the destination.
  • Caches frequently requested external content to save bandwidth.
  • Can bypass geo-restrictions by routing through a different location.
  • Clients must be configured to send traffic through the proxy.
Pros and Cons
Centralized Control

Provides centralized control and monitoring of all outbound requests.

Client Privacy

Protects client privacy since the origin server does not see client IPs.

Bandwidth Savings

Caching reduces bandwidth usage and improves response times.

Single Choke Point

Acts as a single choke point that can fail or add latency.

Client Configuration Needed

Requires client-side configuration or network enforcement to route traffic.

Potential For Misuse

Can be misused to circumvent controls or hide malicious activity.

Code
# A Java HTTP client routing all outbound calls through a forward proxy
HttpClient client = HttpClient.newBuilder()
    .proxy(ProxySelector.of(
        new InetSocketAddress("proxy.corp.local", 8080)))
    .build();

HttpRequest req = HttpRequest.newBuilder()
    .uri(URI.create("https://api.example.com/data"))
    .build();

# example.com sees the proxy IP, not the client's
HttpResponse<String> res =
    client.send(req, BodyHandlers.ofString());
How it works

ProxySelector.of(...) makes the client route outbound calls via the proxy.

The proxy forwards the request, so the destination sees the proxy's IP.

This is client-side configuration - the hallmark of a forward proxy.

The same proxy can cache, filter, or log the traffic centrally.
