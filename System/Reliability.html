Reliability

Reliability is a system's ability to keep performing its function correctly over time, even when parts fail.

A reliable system produces the right result and continues working despite hardware faults, software bugs, or human error.

It is often quantified with metrics like MTBF (mean time between failures) and error rate.

Reliability is closely related to availability but focuses on correctness and consistency of behaviour, not just uptime.

When to use / Key points
  • Design for failure - assume disks, nodes, and networks will fail and handle it gracefully.
  • Use redundancy and replication so no single fault loses data or stops service.
  • Add retries with backoff, timeouts, and idempotency to survive transient faults.
  • Validate inputs and use tested code paths to reduce software-induced failures.
  • Measure with MTBF, MTTR, and error budgets to steer engineering effort.
Advantages
  • Builds user trust and protects revenue and reputation.
  • Reduces emergency firefighting and on-call load.
  • Data integrity is preserved across failures.
Disadvantages / Trade-offs
  • Redundancy and replication increase cost and complexity.
  • Extra safety checks can add latency.
  • Perfect reliability is unattainable; you engineer to a target, not to zero failures.
Code
# Idempotent retry with exponential backoff improves reliability
public Response callWithRetry(Request req) {
    int attempts = 3;
    for (int i = 0; i < attempts; i++) {
        try {
            return client.send(req); # same key => safe to retry
        } catch (TransientException e) {
            if (i == attempts - 1) throw e;
            sleep((long) Math.pow(2, i) * 100);
        }
    }
    throw new IllegalStateException("unreachable");
}
How it works

TransientException is retried; permanent errors propagate immediately.

Math.pow(2, i) spaces retries out to avoid hammering a struggling service.

The request must be idempotent so retries do not double-apply effects.

The final attempt rethrows so the caller learns of true failure.
