Association

Association is a general relationship between objects. Association is a relationship between two classes where objects
of one class are connected to or interact with objects of another class.

Objects are simply related.

Key points
  • Associations relate entities that can exist independently of each other - such as Teacher and Student.
  • The Teacher and Student can exist independently. Neither object owns the lifecycle of the other.
  • The association can be one-to-one, many-to-one or many-to-many.
Code
public class Driver {
    private String name;
    public Driver(String name) {this.name = name;}
}

public class Car {
    private String model;
    public Car(String model) {this.model = model;}

    # Car is associated with a Driver
    public void drive(Driver driver) {
        System.out.println(driver.name + " drives " + model);
    }
}
How association works
  • Car and Driver are independent classes.
  • drive() links a driver to a car when called.
  • Neither object owns or controls the other's lifecycle.
  • This is a plain uses-a relationship between the two.
