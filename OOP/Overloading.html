Method Overloading

Process of writing multiple methods with the same name in the same class is called method overloading.

Method-overloading is a kind of static polymorphism.

Advantages
Improves Readability

Method overloading increases the readability of the program.

Fewer Names to Recall

It avoids the need to memorize multiple method names.

More Generic Code

Method overloading makes our code more generic.

Supports Clean Code

Method overloading supports clean code.

Reduced Complexity

The complexity of the code is reduced.

Compiler Binding

The compiler binds the method call with an appropriate method body.

Method overloading is achieved by
  • Changing the number of arguments.
  • Changing the data type of the arguments.
Code
public class Calculator {
    public int add(int a, int b) {
        return a + b;
    }

    # different parameter types
    public double add(double a, double b) {
        return a + b;
    }

    # different parameter count
    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
How overloading works

All three methods are named add in one class.

They differ by parameter types and count.

The compiler chooses the match based on the arguments.

This is compile-time polymorphism, resolved statically.
