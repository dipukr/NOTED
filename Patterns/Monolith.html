Monolith

Monolithic architecture is a software design pattern where all components of an application, like the user interface, business logic, and data access layer, are built and deployed as a single, unified unit.

Everything runs in one process and is released together.

It is the simplest way to start building and shipping an application.

All modules typically share one codebase and one database.

When to use / Key points
  • Best for small teams, early-stage products, and simple domains.
  • When operational simplicity matters more than independent scaling.
  • One build, one deploy, one runtime to manage.
  • In-process calls make transactions and debugging straightforward.
Pros and Cons
Simple Lifecycle

The application is simple to develop, test, and deploy as a single unified unit.

Easy Debugging

End-to-end debugging is straightforward and transactions stay local within one process.

Low Overhead

Operational overhead is low since there is no network hop between modules.

Tight Coupling

Modules are tightly coupled, so changes in one module can break another.

Cascading Failures

A failure in one module can bring down the entire application.

Full Redeploys

Any change requires re-deploying the whole system, even for small updates.

Code
# All layers live in one deployable; calls are in-process
@RestController
public class CheckoutController {

    private final OrderService orders;
    private final PaymentService payments;

    public CheckoutController(OrderService orders, PaymentService payments) {
        this.orders = orders;
        this.payments = payments;
    }

    @PostMapping("/checkout")
    @Transactional                       # one local ACID transaction
    public void checkout(@RequestBody Cart cart) {
        Order order = orders.create(cart);
        payments.charge(order);        # direct method call, no network
    }
}
How it works

Services call each other directly as Java methods.

@Transactional spans them in one database transaction.

The whole unit is built and deployed together.
