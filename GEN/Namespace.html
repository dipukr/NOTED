Kernel Resources

Kernel resources means the various objects, facilities, and abstractions that the Linux kernel manages and provides to processes. These are the things that user-space programs rely on but don’t directly control—they’re owned and controlled by the kernel.

Examples of kernel resources include:

  • Process IDs (PIDs): Each process is assigned a unique ID. With namespaces, different groups of processes can have their own independent PID space.
  • Mount points / file system view: What filesystems and directories are visible to a process.
  • Network stack: Interfaces, IP addresses, routing tables, firewall rules, etc.
  • IPC objects: Message queues, semaphores, shared memory.
  • User and group IDs (UIDs/GIDs): Identity and permissions of processes.
  • UTS namespace (hostname and domain name): Each group of processes can see a different hostname.
  • Cgroups (control groups): While not a namespace per se, they are another kernel resource for controlling CPU, memory, etc.
