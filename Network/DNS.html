DNS

DNS is a hierarchical and distributed name service that provides a naming system for computers, services, and other resources on the internet or other IP networks.

It translates human-friendly domain names into machine IP addresses.

Resolution walks from root to top-level domain to authoritative name servers.

Results are cached at many levels to speed up lookups.

Key points
  • Every domain-based network call starts with a DNS lookup.
  • Record types include A, AAAA, CNAME, MX, and TXT.
  • TTL controls how long records are cached.
  • GeoDNS redirects users to servers based on geographic location.
Advantages
  • Lets humans use names instead of IP addresses.
  • Distributed and cached for scalability and speed.
  • Enables load balancing and failover via records.
Disadvantages
  • Caching means changes propagate slowly (TTL delay).
  • Vulnerable to spoofing and cache poisoning without DNSSEC.
  • An outage of DNS breaks name resolution broadly.
Code
// Resolving a hostname to IP addresses in Java

void main(String[] args) throws Exception {
    // triggers a DNS query (may hit a cache)
    InetAddress[] addresses =
        InetAddress.getAllByName("example.com");

    for (InetAddress addr : addresses) {
        System.out.println(
            addr.getHostName() + " -> " + addr.getHostAddress());
    }
}
How it works
  • getAllByName asks the resolver to translate the name.
  • The resolver may answer from cache or query name servers.
  • Multiple addresses enable client-side failover.
