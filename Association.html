Association

Association represents a relationship where one object is linked to another object.

Association describes relationships between classes.

The association can be one-way or two-way. Which implies that two classes are related, but neither class owns the other.

Associations relate entities that can exist independently of each other - such as authors and books.

Code
class Driver {
    String name;
    Driver(String name) { this.name = name; }
}

class Car {
    String model;
    Car(String model) { this.model = model; }

    // Car is associated with a Driver
     public void drive(Driver driver) {
        System.out.println(driver.name + " drives " + model);
    }
}
How association works
  • Car and Driver are independent classes.
  • drive() links a driver to a car when called.
  • Neither object owns or controls the other's lifecycle.
  • This is a plain uses-a relationship between the two.
