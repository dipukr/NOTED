Abstract Factory Pattern

Abstract Factory is a creational design pattern that provides an interface for creating families of related or dependent objects without specifying their concrete classes.

Where a Factory Method creates a single product, an Abstract Factory groups several factory methods to produce a whole family of products that are designed to work together.

Client code interacts only with the abstract factory and abstract products, so an entire family can be swapped by changing the concrete factory.

When to use
  • When your system needs to create families of related products together.
  • When products from one family must be used consistently and not mixed with another.
  • When you want to isolate client code from concrete product classes.
  • When you need to support multiple variants (themes, platforms, vendors).
  • When you want to configure a system with one of several product families.
Advantages
  • Guarantees that products from a single family are used together.
  • Isolates concrete classes from the client code.
  • Makes swapping entire product families easy and centralized.
  • Follows the open/closed principle when adding new families.
  • Promotes consistency among the objects produced.
Disadvantages
  • Adds many interfaces and classes, increasing complexity.
  • Adding a new product type requires changing every factory.
  • Can be over-engineered for systems with a single product family.
Code
interface Button  { void paint(); }
interface Checkbox { void paint(); }

class WinButton   implements Button   { public void paint(){ System.out.println("Win button");} }
class WinCheckbox implements Checkbox { public void paint(){ System.out.println("Win checkbox");} }

# Abstract factory: a family of related products
interface GUIFactory {
    Button createButton();
    Checkbox createCheckbox();
}

class WinFactory implements GUIFactory {
    public Button createButton()     { return new WinButton(); }
    public Checkbox createCheckbox() { return new WinCheckbox(); }
}

void main() {
    GUIFactory factory = new WinFactory();
    factory.createButton().paint();
    factory.createCheckbox().paint();
}
How the Abstract Factory works
  • Button and Checkbox are abstract products of one family.
  • GUIFactory declares creation methods for the whole family.
  • WinFactory produces matching Windows-style widgets that belong together.
  • The client uses only the factory and product interfaces; swapping to another factory changes the entire look.
