1. Kafka Overview

Apache Kafka is a distributed event streaming platform designed for high-throughput, fault-tolerant, and scalable messaging.

  • Millions of messages per second
  • Durable append-only log
  • Horizontal scaling using partitions
  • Replication for fault tolerance
  • Exactly-once support with transactions

Traditional Messaging vs Kafka

FeatureTraditional QueueKafka
StorageQueuePersistent Log
ReplayUsually NoYes
ScalingLimitedExcellent
RetentionConsumed messages removedConfigurable
2. Kafka Architecture
  • Producer publishes events.
  • Topic stores related events.
  • Partition provides ordering and scalability.
  • Broker stores partitions.
  • Consumer reads events.
  • Consumer Group enables parallel processing.

3. Topics and Partitions

Messages inside a partition remain ordered.

Producer with Key
ProducerRecord<String,String> record =
    new ProducerRecord<>("orders","cust123","Order Created");

The same key consistently maps to the same partition.

4. Kafka Producer Java API

Create Producer

Producer Configuration
Properties props = new Properties();
props.put(ProducerConfig.BOOTSTRAP_SERVERS_CONFIG, "localhost:9092");
props.put(ProducerConfig.KEY_SERIALIZER_CLASS_CONFIG,
          StringSerializer.class.getName());
props.put(ProducerConfig.VALUE_SERIALIZER_CLASS_CONFIG,
          StringSerializer.class.getName());

KafkaProducer<String,String> producer = new KafkaProducer<>(props);

Synchronous Send

Sync Send
RecordMetadata metadata = producer.send(
    new ProducerRecord<>("orders","Hello")
).get();

Asynchronous Send

Async Callback
producer.send(
    new ProducerRecord<>("orders","Hello"),
    (metadata, exception) -> {
        if(exception == null){
            System.out.println(metadata.partition());
        }
    }
);

5. Kafka Consumer Java API

Create Consumer

Consumer Configuration
Properties props = new Properties();
props.put(ConsumerConfig.BOOTSTRAP_SERVERS_CONFIG,"localhost:9092");
props.put(ConsumerConfig.GROUP_ID_CONFIG,"order-group");
props.put(ConsumerConfig.KEY_DESERIALIZER_CLASS_CONFIG,
          StringDeserializer.class.getName());
props.put(ConsumerConfig.VALUE_DESERIALIZER_CLASS_CONFIG,
          StringDeserializer.class.getName());

KafkaConsumer<String,String> consumer =
    new KafkaConsumer<>(props);

Subscribe and Poll

Polling Loop
consumer.subscribe(List.of("orders"));

while(true){
    ConsumerRecords<String,String> records =
        consumer.poll(Duration.ofMillis(500));

    for(ConsumerRecord<String,String> record : records){
        System.out.println(record.value());
    }
}

Manual Offset Commit

Manual Commit
consumer.commitSync();

10. Kafka Streams API

Kafka Streams is a Java library for real-time stream processing.

Word Count Example
StreamsBuilder builder = new StreamsBuilder();

KStream<String,String> stream =
    builder.stream("input-topic");

stream.flatMapValues(v -> List.of(v.split(" ")))
      .groupBy((k,v) -> v)
      .count()
      .toStream()
      .to("output-topic");

Common Operations

  • map
  • filter
  • flatMap
  • groupBy
  • count
  • join
  • aggregate
  • windowed aggregation
