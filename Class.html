Class

A class body contains specification of a set of fields which defines attributes of the objects and a set of methods which defines behaviours of the objects.

Class is the unit of modularization in object oriented program.

A class is a blueprint which defines the attributes (fields) and behaviours (methods) common to a number of objects.

A class is a user defined blueprint based on which objects are created.

Object is a concrete entity with a set of attributes and a set of behaviours.

Object also have identify, lifetime and scope and belongs to a class.

Fields defines the attributes of objects instantiated from a class.

Methods defines the behaviors of objects instantiated from a class.

Objects maintain state in instance variables (attributes).

Objects are allocated from the heap and accessed by reference variables.

Objects communicates with one another by sending and receiving message.

Code
public class Car {

    // fields (state)
    private String model;
    private int speed;

    // constructor
    public Car(String model) {
        this.model = model;
        this.speed = 0;
    }

    // behaviour
    public void accelerate(int delta) {
        speed += delta;
    }

    public int getSpeed() {
        return speed;
    }
}

void main() {
    Car car = new Car("Tesla");
    car.accelerate(60);
    System.out.println(car.getSpeed());
}
How the class works
  • Car is the blueprint; car is an object created from it.
  • model and speed are fields holding each object's state.
  • The constructor initialises the object when new is used.
  • accelerate() and getSpeed() define its behaviour.
