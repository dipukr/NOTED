Data-Oriented Design

Data-Oriented Design (DOD) is a software engineering approach focused on organizing data for optimal CPU cache usage and performance, rather than modeling based on object-oriented hierarchies.

By using layouts like Array of Structures (AoS) or Structure of Arrays (SoA), DOD prioritizes efficient memory access, reducing cache misses and data movement. This is critical for high-performance applications such as video games.

Key Aspects of Data-Oriented Design
  • Focus on Data Layout: DOD prioritizes how data is structured in memory, aiming for contiguous, cache-friendly layouts, for example separating data into arrays based on when it is needed.
  • Performance Optimization: It reduces CPU stall time by making sure data is already in the cache when it is needed, often giving significant speedups.
  • Contrasted with OOD: Object-Oriented Design focuses on “nouns” (objects, state and behavior); DOD focuses on the transformations applied to data.
  • Entity-Component-System (ECS): A common, practical implementation in game development, where entities are just IDs, components are raw data, and systems transform the data.
  • Hardware Awareness: DOD considers the underlying hardware, such as cache lines and memory bandwidth, to create more efficient algorithms.
