Method Overriding

Method-overriding is the process of redefining a parent class instance method into its child class is known as method overriding.

An instance method defined in the parent class is redefined into its child class to give specific implementation of the parent class method.

Referenced object type, not the reference variable type determines which method will be called.

When we create a parent class reference variable and assign a child class object then calling an overridden method on that variable will call the child class behaviour.

Key points
  • Final methods can not be overridden.
  • Static methods can not be overridden.
  • Private methods can not be overridden.
  • Child class method is called overriding method.
  • Parent class method is called overridden method.
  • Overridden methods are dynamically dispatched.
  • Finalize method can be overridden to free system resources.
  • Overridden parent class method can be called using super keyword.
  • Runtime polymorphism can be achieved through method overriding.
  • Abstract methods can only be overridden by the first concrete class.
  • The access level cannot be more restrictive than the overridden method.
  • Override annotation denotes that the method overrides the base class method.
Code
class Shape {
    public String name() { return "shape"; }
}

class Circle extends Shape {
    @Override
    public String name() {   // same signature
        return "circle";
    }
}

void main() {
    Shape s = new Circle();
    System.out.println(s.name());   // prints circle
}
How overriding works
  • Circle redefines name() with the same signature.
  • @Override tells the compiler to verify the match.
  • The Shape reference points to a Circle object.
  • Dynamic binding calls Circle.name() at runtime.
